# EVay Lanka 🚗⚡
### Intelligent EV Ecosystem Application for Sri Lanka

EVay Lanka is a mobile-based Electric Vehicle (EV) ecosystem application developed to support EV users in Sri Lanka through intelligent route planning, charging station discovery, battery simulation, and energy analytics.

The project aims to reduce range anxiety and improve the EV user experience by providing localized smart mobility solutions tailored for Sri Lankan conditions.

---

## 📌 Features

- 🔋 Battery health and range simulation
- 📍 Charging station discovery using Google Maps
- 🛣 Smart EV route planning
- 📅 Charging slot booking system
- 💰 Energy cost and petrol cost comparison
- 🌱 CO₂ savings analytics
- 🌐 Multilingual support (Sinhala, Tamil, English)
- ⚡ Localized EV ecosystem for Sri Lanka

## 🧠 Innovative Concept

EVay Lanka introduces a localized EV management ecosystem designed specifically for Sri Lankan EV users. The system considers local challenges such as:

- Uneven charging infrastructure
- Tropical climate conditions
- Electricity tariff variations
- Limited EV analytics platforms
- Multilingual accessibility

The project also explores intelligent EV trip planning and predictive battery simulation to improve travel confidence and reduce range anxiety.

## 📱 System Modules

### User Authentication
Secure login and registration using Firebase Authentication.

### Charging Station Locator
Locate nearby charging stations through integrated Google Maps services.

### Smart Route Planning
Generate optimized routes for EV travel with charging considerations.

### Battery Simulation
Estimate battery range, charging time, and energy consumption.

### Analytics Dashboard
View charging costs, energy usage, and CO₂ savings.
